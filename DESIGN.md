# Tu Espacio · Sistema visual

Superficies de operación: la prioridad es completar una reserva o gestionar un cupo. Conservar el nombre y el símbolo de parqueo, reducir el exceso de redondeado y ofrecer una composición útil en escritorio y móvil.

- Fondo claro ligeramente cálido `#F6F7F5`, superficies blancas, navegación verde tinta `#142F2D`; verde `#246249` para la acción principal y confirmación. El acento claro `#D8EDB5` identifica la marca sobre la navegación. Los estados de advertencia y error tienen texto e icono además de color.
- Navegación lateral persistente en escritorio; barra inferior móvil. Cabecera con región, fecha local y cuenta. El contenido usa un ancho de lectura controlado y se reorganiza al faltar espacio.
- Una familia sans del sistema; pesos 400, 500, 600 y 700. Números tabulares en importes y métricas. Títulos 24–32 px, cuerpo 14–16 px, apoyo mínimo 12 px.
- Escala de espacio 4/8/12/16/24/32/48. Radios 8 para controles, 12 para superficies y 999 solo para etiquetas de estado. Bordes para agrupar; sombra únicamente en diálogos y elementos superpuestos.
- El mapa esquemático utiliza calles, zonas y pines para comparar destinos. Se identifica como ilustrativo. Las métricas provienen del servidor y muestran cero o estado vacío cuando corresponde.
- Selección y foco visibles. Botones con estados de envío, error y deshabilitado. Confirmación explícita de cancelaciones. Las transiciones duran 160 ms y se suprimen con movimiento reducido.
- Tema oscuro con el mismo significado semántico y contraste. Ninguna integración de prueba se presenta como un servicio comercial real.
